# 查新检索报告模板

交付格式默认**对话内 Markdown**，可选 docx / PDF。MD 直接按下列结构在对话内交付；选 PDF 时经 HTML 中转排版（封面：标题 + 方案名称 + 日期 → 正文 → 页脚注明"基于专利文献检索的技术分析意见，不构成法律意见"）。docx 按 office 文档流程转换，**保持本模板的章节编号与表格结构**。

预检级报告（A1 选③或 A2 选快速预检）：删去 7.2、7.4、8.2，第 1.2 节只给新颖性结论，并在报告头注明降级原因与由此产生的局限。

```
查新检索报告

0 报告头
  方案名称、委托方、技术领域、拟申请地区、拟申请类型（发明/实用新型）、
  基准日（按情形注明：尚无正式申请文件 → 拟申请日，未定则检索执行日；
  已有正式申请文件 → 实际申请日；主张优先权 → 优先权日。须注明取哪个及理由）、
  **基准日后公开文献的处理方式（检索不设公开日上限）**、
  数据库、检索语种、检索执行日、检索式数量（全表）、
  对比文件数量（按 X/Y/A 分组）、风险文献数量、报告级别（完整/预检）、报告日期
  声明：基于专利文献检索的技术分析意见，不构成法律意见

1 结论摘要
  1.1 总体判断（一段话：方案能否授权、主要障碍是哪几篇、
      最值得作为区别特征的是哪一点、建议往哪个方向限缩）
  1.2 逐项结论表
      权项（拟写或已提交）/ 关键特征 / 结论（已公开·部分公开·组合公开·未检到）/
      主证据（D 编号 + 段落号）/ 组合层数 / 授权前景（高·中·低）

2 检索概况
  2.1 目的与范围（用途、基准日、时间范围说明、数据库）
  2.2 检索要素与分类号（E 表四维度 + 主分类 + 降噪排除 + 发明点三路径检查结果）
  2.3 检索式与命中（全表 #1–#18 及子编号：
      编号 / 思路 / 覆盖目标（权项+特征）/ 要点 / 命中数 / 备注）
  2.4 补充检索（引证追溯 / 申请人发明人 / 非专利文献）

3 技术方案分析
  3.1 方案来源与完整度（交底书 / 口述补齐 / 仅主题词，含补齐了哪些信息）
  3.2 方案概述（背景 / 问题 / 方案 / 机理）
  3.3 技术问题表（Q1–Qm：问题 + 交底书/申请文件原文引用）
  3.4 技术特征分解（C1-1–Cn-m：特征 / 权项 / 交底书或申请文件依据；
      ★ 标注发明点；权项布局未定时注明"为 SKILL 拟设"）

4 技术方案解释
  4.1 解释原则与方法（通读全文取最合理含义，单一口径）
  4.2 歧义措辞解释表（措辞 / 确定的含义 / 依据 / 对检索与结论的影响）
  4.3 待用户核对清单（B2 记录：用户是否改口径、改了哪几处、影响范围）

5 对比文件
  5.1 一览表（D1–Dn：编号 / 公开号 / 申请人 / 公开日 / 类别 X·Y·A /
      涉及特征 / 一句话要点）
  5.2 定级表（要点前置：D 编号 / 公开号 / 申请人 / 公开日 / 要点 /
      类别 / 涉及特征 / 定级理由 / 关键段落号）+ 要点解读
      （不设特征覆盖矩阵、不设公开时间线；距基准日 2–3 个月内的临界
      公开日文献，在表内标注"需官方公报核对公开日"）
  5.3 风险清单（基准日后公开的同主题文献：公开号 / 申请人 /
      公开日 / 与本方案重叠程度 / 风险说明）
      —— 本节文献不入 D 编号，不作对比文件

6 逐项技术特征比对（每特征一小节，★ 发明点优先展开）
  格式：各文献相关段落号列举 → 小结（已公开 / 部分公开 / 未检到 +
  一句话判断 + 不确定性提示）

7 新颖性与创造性评价
  7.1 新颖性（最接近 2–4 篇逐特征比对 + 不确定点 + 结论 + 使用建议）
  7.2 独立权利要求创造性（每条组合三步法：最接近文献 → 区别特征与
      重新确定的技术问题 → 技术启示；跨领域转用论证含在第 3 步内）
  7.3 从属权利要求（权项 / 引用关系 / 附加特征 / 评价 / 前景）
  7.4 审查员驳回预演（可能的驳法 / 依据 / 我方应对 / 风险等级）
      含：单篇否定新颖性、两篇组合否定创造性、公知常识补足、常规选择认定

8 结论与建议
  8.1 授权前景矩阵（权项 × 前景 × 主证据 D 编号 × 组合层数）
  8.2 核心障碍与区别点（最接近文献 / 区别特征 / 为何仍可能被驳 /
      论证需补什么）
  8.3 撰写方向建议（**只给方向，不代写权利要求**）
      · 独立权项：往哪个特征限缩最经济、哪些特征放从权
      · 说明书：需补哪些效果数据、对比实验、参数范围支撑
      · 从权布局：几张从权、覆盖哪些替代方案
      · 是否需要分案 / 是否需调整申请类型（发明 vs 实用新型）
  8.4 局限与声明
      数据库范围、非专利文献覆盖情况、语言盲区、附图处理方式、
      参数确认情况（哪些为默认值）、"未检到≠不存在"、
      **本报告未评价撰写质量缺陷（26.3/26.4/33）与 25 条客体、9 条重复授权**、
      **本报告不是 FTO 分析，不评价是否侵犯他人权利**、
      "本报告不构成法律意见"

附录 A 专利号清单（目标 / X·Y 类 / A 类 / 风险文献，分号分隔可直接批量导入）
附录 B 检索式全表
```

## 填写要求

- **编号只用 D1–Dn**，法律类别写在"类别"列（X/Y/A）。风险文献不编 D 号，另立 5.3 清单；
- 第 1.2 节逐项结论表是全文最常被直接引用的部分，**必须每条都带 D 编号与段落号**，不能只写"已被 D3 公开"；
- 第 4 章必须在第 5、7 章之前（解释定不下来，比对就没有基准）；
- **不设撰写质量章节**：26.3 / 26.4 / 33、25 条客体、9 条重复授权不在本报告范围，**既不设章节、也不给结论**；最多在结论摘要里一句话提示，并在 8.4 局限中声明；
- **8.3 只给方向不代写**：撰写建议是给客户的决策依据，不是权利要求草案。真要代写，须用户另行确认后另起任务；
- 第 5.3 节不能合并进 5.1/5.2——基准日后公开的文献一旦混进对比文件表，读者会误以为它们能用来否定自己的申请。
