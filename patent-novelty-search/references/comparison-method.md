# 查新检索-比对方法

# 特征分解与比对评价方法（查新专用）

## 1. 技术特征分解（C 表）

查新的对象分两种：尚无正式申请文件时是自己的技术方案，已有正式申请文件时是已提交的权利要求。比对的单元都是"一个完整技术方案"，因此特征编号按**权项**（拟写或已提交）编排。

| 特征   | 内容 | 权项 | 依据（交底书/申请文件） |
| ---- | -- | ---- | --------- |
| C1-1 | …  | 权1   | [xxxx]    |
| C1-2 | …  | 权1   | [xxxx]    |
| C2-1 | …  | 权2   | [xxxx]    |

规则：

- **编号规则**：`C<权项号>-<序号>`，`C1-1` = 拟写权 1 第 1 个特征；每条独权/从权逐项拆完，权项内连续编号；
- **查新对象分两种情形**：尚无正式申请文件时按**拟写权利要求**编排；已有正式申请文件时按**已提交的权利要求**逐项编排。后者每一个权项都要拆，不得只拆独权；
- **权项布局尚未确定时**：全部特征先记在 `C1-*` 下，待撰写阶段再权项化——但报告中要注明"权项布局为 SKILL 拟设，最终以撰写方案为准"；
- **跨权项重复的特征只在首次出现的权项下编号**，其余括注引用（如 `C1-3（同 C4-2、C5-1）`），避免同一特征被重复计数、虚增区别特征条数；
- 区分**步骤/结构限定**与**目的/效果限定**——后者单独标记，比对时按"是否起限定作用"处理：目的或效果限定若不带来结构或步骤变化，相同性判断中不予考虑；反之会虚增区别特征，把本该被破坏的新颖性做成"有区别"；
- 交底书中有明确定义的术语（术语 = 具体数值或判定标准）单独摘录，作为解释素材；
- **发明点单独标星**（★），检索火力与篇幅向标星特征倾斜；常规特征用宽泛式带过即可。

## 2. 对比文件定级

**编号一律 `D1、D2…Dn` 连续编号**；法律类别只放在"类别"列用 X/Y/A 表达。编号不带类别含义，改级时按需调整编号与顺序。

**列序（要点前置）**：D 编号 / 公开号 / 申请人 / 公开日 / **要点（一句话）** / 类别（X·Y·A）/ 涉及特征（C1-1、C1-3…）/ 定级理由 / 关键段落号。

**风险文献不进 D 编号表**：基准日之后公开的同主题文献单列"风险清单"（公开号 / 申请人 / 公开日 / 与本方案重叠程度 / 风险说明）。理由——它们不是对比文件，混进 D 编号表会让读者误以为可用于评价。

**定级确认（B1）**：交用户确认后锁定并进入评价，锁定后即做 X/Y 类外文文献的中文要点翻译。

表后写**"要点解读"**：

- 哪种特征没有一篇文献完全公开（**区别点/护城河**，决定新颖性与创造性能否守住）；
- 哪些特征需几篇组合才能覆盖（组合层数多 → 该特征相对稳，撰写时可往这里限缩）；
- 有无临界公开日文献（距基准日 2–3 个月内的，须以官方公报核对公开日）。

## 3. 新颖性评价（逐篇单独比对）

关键纪律：

- **单独对比原则**：每一项权项（拟写或已提交）分别与每一份文献单独比对，**不得组合**。组合是创造性的事，混进来就是法律错误；
- **"直接的、毫无疑义地确定"标准**：文献必须明确记载该特征，不能靠推理补足；
- **列全部不确定点**：中间态结构是否算完整特征、该工艺条件下能否产生所声称的问题/效果、该文献处理的是否为本案所指的对象。逐条写出，并给使用建议（如"建议作创造性证据，不作新颖性主证据"）。

### 3.1 抵触申请：先判"同样的发明创造"

抵触申请只能打新颖性，法定要件是"同样的发明创造"（22.2 第 2 款）。判的是**技术方案是否实质相同**，不看文字相似度：

| 情形                                                      | 结论                      |
| ------------------------------------------------------- | ----------------------- |
| 技术手段、所要解决的技术问题、技术效果三者实质相同；文字表述不同（同义词替换、上下位概念、步骤换序但功能不变） | **构成**抵触申请              |
| 文字高度相似，但解决的技术问题不同，或手段有实质差别（缺少必要技术特征、参数范围不重叠）            | **不构成**，降为现有技术或背景文献     |
| 仅部分特征重叠                                                 | **不构成**——部分重叠不够，必须是完整方案 |

四条判据：

- 比对单元仍是权项级：以目标权项的**全部**技术特征为准，逐特征确认是否被在先申请公开，标准同新颖性——"直接的、毫无疑义地确定"，不得靠推理补足；
- 权项类型不同（一项产品、一项方法）不影响判断——看技术方案，不看权项类型；
- **两份文本都读到全文再判**，尤其不要用摘要判"不同"：摘要常省略关键步骤，容易把"实质相同"误判成"不同"，也会把"实质不同"误判成"相同"；
- 时间要件逐项核：在先申请的**申请日**须早于基准日，其**公开日**须不早于该基准日。**抵触申请制度只适用于中国申请**——拟申请 EP/US 时不要套用此判断，只把这类文献列为潜在障碍。

## 4. 创造性评价（三步法，查新必须做）

每条证据组合按固定格式：

1. **最接近的现有技术**：公开特征最多、同领域同申请人的优先。**优先同申请人文献**是实务技巧而非条文——结合动机天然成立，还可能构成自认；
2. **区别特征与实际解决的技术问题**：基于区别特征在方案中的作用**重新确定**，**不得照抄交底书/申请文件自述问题**。这是防止事后诸葛亮的核心机制：先知道答案再倒推"问题显而易见"，是审查意见里很常见的错误；
3. **是否显而易见**，按区别类型分五种应对：
   - **顺序类**：找同领域"该工序先后顺序属标准做法"的文献；
   - **参数类**：多文献端点/区间拼合 + "属常规选择、说明书未述特殊效果"论证；
   - **目的类**：列"出于该目的采用后续处理属常规思路"的动机文献（注明段落号）；
   - **结构类**：该结构已被公开 + 该结构只是常见或细微的改动；
   - **领域类**：本领域技术人员有无动机去该领域找（技术问题的共通性、功能一致性）、领域跨度（同机理还是同结构）、转用需改动多少（有无阻碍因素），结论写成"可以结合 / 难以结合"。

**组合成立的三个要件**（缺一即被审查员抓住）：①每篇证据自身公开了对应特征；②时间上都是基准日前的现有技术（抵触申请不得入组合）；③有结合动机。第③项最容易被忽略，也最容易被攻破——"两篇都公开了这些特征"并不等于"应当结合"。

**"属公知常识"要有书证，不能只写结论。** 主张某区别特征属公知常识、常规选择或常规实验手段（参数类、目的类论证里最常用），须以**教科书、技术手册、工具书、国家或行业标准**佐证，注明书名（含版次）、页码、原文表述，作为证据附上。专利文献的一般性记载只能作辅助，不能单独支撑"显而易见"——某篇专利写了不等于本领域普遍知晓，这是审查员最常直接驳回的一类论证。手边确实没有书证时，把该主张写成"倾向性意见，尚需补充公知常识性证据"，并列入补充方向，**不得作为组合成立的主要理由**。

### 4.1 审查员驳回预演（查新特有）

与无效检索的"抗辩预演"不同——查新是站在**审查员**一侧预判，目标是提前找出会被驳的点：

| 审查员可能的驳法 | 依据什么 | 我方可能的应对 | 风险 |
| --- | --- | --- | --- |
| 单篇 X 类否定新颖性 | D 编号 + 段落号 | 区别特征往从权下沉 / 限缩参数范围 | 高/中/低 |
| 两篇组合否定创造性 | D1+D2，结合动机段落 | 论证结合存在阻碍 / 补效果数据 | 高/中/低 |
| 公知常识补足区别特征 | 教科书页码 | 证明该特征产生预料不到的效果 | 高/中/低 |
| 认定区别特征为常规选择 | 多篇同领域文献 | 说明选择带来的非显而易见效果 | 高/中/低 |

预演要写"审查员会怎么打"，而不是"我方为什么能赢"——查新报告的价值就在于提前暴露被打的风险。

## 5. 授权前景用语（统一）

- 前景：**高 / 中 / 低**（"高"= 现有技术难以否定，即授权障碍小），报告开头须注明方向；
- 按**权项逐项**给（拟写或已提交），每项写明依据 D 编号 + 段落号 + 主要障碍 + 可修改方向；
- 新颖性维度单独标：**未破坏 / 存疑（注明理由与文献） / 被破坏**；
- **"能不能授权"与"有多大概率授权"分开写**：前者是法律判断（特征是否被公开、组合是否有启示），后者还取决于审查员对解释的采纳、领域实践、撰写质量。合并成一句"前景良好"是不专业的。

## 6. 结论口径（B4）

- **完整口径（默认）**：所有结论含存疑项一并写入；存疑项标"存疑"+原因（检索盲区 / 文献不确定点 / 解释取向未定 / 证据形式待核），不隐藏不确定性；
- **保守口径**：仅用户主动选择时启用——正文只写有把握的结论，存疑项集中附录；
- 两种口径下，"未检到≠不存在"的局限声明都必须保留；
- **结论必须落到"下一步怎么办"**：往哪限缩、补什么数据、哪个特征最值得作为区别点。只给"前景中等"而不给方向的查新报告，客户拿不走任何东西。
