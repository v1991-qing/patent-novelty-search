# Patent Novelty Search Skill（专利查新检索 Skill）

面向 AI Agent（CodeBuddy / Claude / OpenClaw 等支持 Agent Skills 的客户端）的专利查新检索技能：以自有技术方案或已提交申请的权利要求为起点，完成检索、对比文件定级、新颖性/创造性逐项评价、审查员驳回预演，并给出**授权前景高/中/低**的逐项结论。

## 技能定位

| 维度 | 说明 |
|---|---|
| 时机 | 申请日之前（撰写/申请/立项阶段） |
| 目的 | 评估新颖性·创造性，判断授权前景，为撰写策略提供依据 |
| 起点 | 自己的技术方案（交底书）或已申请但未授权的权利要求 |
| 检索要求 | **求全**：宁可多检、不留盲区，检索不设公开日上限 |
| 产出 | 查新检索报告（含授权前景结论、风险清单） |

配套技能：**patent-invalidity-search**（已授权专利的无效检索/稳定性分析），两者方法论同构、确认点编号体系一致（A/S/B 三段），仅时间界限与产出不同。

## 核心特性

- **12 个交互式确认点**（A1–A5 启动 / S1–S3 检索 / B1–B4 评价输出），一张确认表收完启动参数、可整体跳过；
- **检索式全表 #1–#18**：先新颖性思路（单篇 X 类）后创造性思路（结合动机），按语种/权项展开后约 18–42 条，每条必须标注"服务哪条权项、覆盖哪几个特征"；
- **基准日按情形确定**：尚无正式申请文件 → 拟申请日（未定则检索执行日）；已有正式申请文件 → 实际申请日；主张优先权 → 优先权日；部分优先权逐项分列；
- **抵触申请不设专项检索**：命中文献按公开时间分类（现有技术 / 抵触申请 / 风险文献），抵触申请仅限中国申请、仅用于新颖性；
- **创造性必须评**：三步法 + 公知常识须教科书书证（书名/版次/页码）+ 审查员驳回预演（四种驳法 × 应对 × 风险等级）；
- **报告 0–8 章 + 附录**：结论摘要逐项带 D 编号与段落号；基准日后公开的同主题文献单列"风险清单"，不入对比文件表。

## 安装

### CodeBuddy

```bash
cp -r patent-novelty-search ~/.codebuddy/skills/
```

### WorkBuddy / OpenClaw

```bash
cp -r patent-novelty-search ~/.workbuddy/skills/
# 或
npx -y clawhub install patent-novelty-search
```

### Claude Code

```bash
cp -r patent-novelty-search ~/.claude/skills/
```

安装后在对话中说"查新检索""专利查新""这个方案能不能授权"等触发词即可调用。

## 触发词

查新检索、专利查新、新颖性检索、申请前检索、专利性检索、能否授权、授权前景、交底书检索、现有技术检索、技术方案检索。

## 范围边界

本技能只处理**文献能否否定新颖性/创造性**的问题，不评价撰写质量缺陷（26.3/26.4/33）、25 条客体、9 条重复授权，也**不是 FTO 侵权风险分析**。触发相关问题时技能会一句话说明超出范围并建议另起任务。

## 免责声明

本技能输出为**基于专利文献检索的技术分析意见，不构成法律意见**。正式申请、无效、诉讼等事项请咨询专利代理师/律师。
